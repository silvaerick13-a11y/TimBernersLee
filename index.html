Tim Berners-Lee

O criador da World Wide Web

Quem foi Tim Berners-Lee?

Timothy John Berners-Lee nasceu em Londres em 1955. Ele é um cientista da computação britânico que transformou a sociedade ao criar a World Wide Web em 1989 enquanto trabalhava no CERN (Organização Europeia para a Pesquisa Nuclear).

A História da Criação da Web

Originalmente, a web foi proposta para ajudar cientistas a compartilhar dados entre diferentes computadores. Tim desenvolveu os pilares fundamentais:

  • HTML: Linguagem de marcação para criar páginas.
  • HTTP: Protocolo para transferência de dados.
  • URL: Sistema de endereçamento de páginas.

Em 1993, o CERN liberou o código-fonte da Web para o domínio público gratuitamente, permitindo que a internet se expandisse pelo mundo.
